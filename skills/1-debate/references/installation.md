# Install debate harnesses

This workflow needs the selected CLI agents from `codex`, `claude`, and `agy`.
Install only the agents selected for the debate; all three are not mandatory.

Read [harness installation](../../0-harness/references/installation.md) for
macOS install commands, PATH setup, and verification for each CLI.

Check each selected binary with `command -v` and its `--version` before starting.
Complete required account setup before unattended execution. Then read
[0-harness](../../0-harness/SKILL.md) for permissions and command patterns.
A missing agent must be reported; do not silently substitute another harness.
