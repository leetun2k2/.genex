# Install debate harnesses

Install only the harnesses selected for the debate; all three are not mandatory.
Use [1-harness](../../1-harness/SKILL.md) for selection, then the selected execution skill and its installation reference:

- [Codex](../../0-codex/SKILL.md) — [installation](../../0-codex/references/installation.md).
- [Claude Code](../../0-claude/SKILL.md) — [installation](../../0-claude/references/installation.md).
- [Antigravity](../../0-antigravity/SKILL.md) — [installation](../../0-antigravity/references/installation.md).

Complete required account setup before unattended execution. A missing assigned harness must be reported; do not silently substitute another.
